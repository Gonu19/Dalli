# DEMO.md — 시연 대본 90초

## 전제
- **`ReplaySource`로 시연.** 무대에서 뛸 수 없음 → 실센서 의존 시 시연 불가
- 리플레이 시나리오: 초반 과속 → 개입 → 회복 실패 → 목표 하향 → 완주 (20분 러닝을 **10배속**, 약 2분)
- `seed.py`로 과거 기록 7~10일치 + 캘린더 계획 미리 생성
- 기기 무음 해제, 볼륨 최대, 외부 음악 앱(스포티파이 등) 재생 중 상태로 시작 ← **차별점 시각화**

## 대본
| 초 | 화면 | 멘트 |
| --- | --- | --- |
| 0–10 | 홈 | "초보 러너는 자기 페이스를 몰라 초반에 과속하고, 10분 뒤 걷습니다. 달리는 케이던스로 이걸 잡습니다." |
| 10–20 | 홈 (목표·컨디션 선택) | "오늘 20분, 컨디션은 보통. 제 기준 리듬 157에 맞춰 목표 범위가 잡힙니다." — **음악 재생 중임을 보여줌** |
| 20–30 | `/run/active` | "시작. 화면은 이제 안 봅니다. 범위 안이면 앱은 아무 소리도 내지 않습니다." |
| 30–45 | 과속 구간 | (음성 개입 재생) "리듬이 빨라지자 3초짜리 한 문장. 음악은 안 끊깁니다." |
| 45–60 | 회복 실패 → 하향 | "쿨다운 60초 뒤에도 회복이 안 되면, 실제로 유지 중인 리듬 기준으로 **목표를 낮춥니다.** 실패가 아니라 조정입니다." |
| 60–75 | `/run/report` | "완주. 리듬 유지율 72%, 피로도 0.34. AI가 한 줄 판정과 다음 러닝 처방 한 가지를 줍니다." |
| 75–90 | `/record` 캘린더 | "기록은 캘린더로 이어집니다. 앱 없이 뛴 날도 수기로 남습니다. 누적 10일 — 달리는 한 번의 운동을 루틴으로 만듭니다." |

## 강조 3가지
1. **Silent by default** — 범위 안에서는 무음. 외부 음악 안 끊김
2. **목표 하향** — 실패로 처리하지 않고 현실적 범위로 조정 (경쟁 앱과의 차이)
3. **루틴 연결** — 러닝 1회로 끝나지 않고 캘린더·수기 기록까지

## 리허설 체크리스트
- [ ] ReplaySource 시나리오가 개입 1회 + 하향 1회를 반드시 포함하는가
- [ ] AI 리포트 8초 타임아웃 → 폴백 문구가 정상 출력되는가 (**네트워크 죽어도 시연 진행돼야 함**)
- [ ] seed 데이터로 캘린더·분석 탭이 비어 보이지 않는가
- [ ] 기기 미러링 지연 확인, 오디오가 미러링에도 들리는가
- [ ] 배터리 50% 이상, 알림·방해금지 설정
- [ ] 백업: 화면 녹화 영상 준비 (라이브 실패 대비)

## 금지
- 무대에서 실센서 사용
- 라이브 API 호출 의존 (서버 다운 = 시연 종료) → 로컬 서버 or 캐시된 응답 폴백 준비
- 90초 넘기기
