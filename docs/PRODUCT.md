# PRODUCT.md — 기획 요약 · 페르소나 · 톤 규칙

## 1. 서비스
- **달리(Dalli)** — "달리다"의 "달리"
- 한 줄: 초보 러너의 개인 케이던스를 기준으로 무리 없는 **완주를 돕고**, 기록·계획을 **일상 루틴으로 연결**하는 러닝 앱
- 핵심 메시지: **더 빠르게가 아니라, 끝까지 달릴 수 있는 리듬을 찾아준다**

**아닌 것**: 음악 제공/배속 조절 앱 아님. 사용자는 기존 플레이리스트를 그대로 듣고, 앱은 필요한 순간에만 짧게 개입.

## 2. 문제
초보자는 적정 페이스·케이던스를 모름 → 초반 과속 → 급격히 지쳐 걷거나 포기.
기존 앱은 거리·속도·순위·경쟁 중심. 초보자에게 필요한 것:
- 지금 리듬이 무리인지 알기
- 화면 안 보고 페이스 조절
- 피로할 때 목표 낮추기
- 작은 완주 경험 쌓기
- 앱 안 켠 날까지 포함한 루틴 관리

## 3. 페르소나 — 김민지 (22, 대학생)
- 러닝 경험: 가끔 시도, 꾸준하지 못함 / 장비: 스마트폰 + 무선 이어폰
- 목표: 20분 이상 멈추지 않고 달리기
- 현 상태: 빠르게 시작 → 약 10분 후 지쳐 걸음

| Pain Point | Needs → 대응 기능 |
| --- | --- |
| 맞는 페이스·케이던스를 모름 | 기준 리듬을 알고 싶다 → 온보딩 + 기능1 |
| 러닝 중 화면 보기 어려움 | 필요한 순간에만 안내 → 기능1 |
| 잦은 음성이 몰입 방해 | 외부 플레이리스트 그대로 → 기능1 |
| 목표 미달 = 실패로 느낌 | 목표 조정 괜찮다는 안내 → 기능1 |
| 계획·기록 습관 없음 | 완주 경험 축적 → 기능3 |
| 잘 달렸는지, 뭘 바꿀지 모름 | 조언 1개 + 현실적 목표 → 기능2 |

## 4. 사용 전·후
| 전 | 후 |
| --- | --- |
| 초반 과속 | 개인 기준 리듬 설정 |
| 화면 계속 확인 | 필요할 때만 음성·메트로놈 |
| 음악 템포에 억지로 맞춤 | 음악은 그대로, 리듬만 별도 안내 |
| 피로해도 같은 속도 고집 | 회복 안 되면 현실적 범위로 조정 |
| 한 번 실패하면 포기 | 완주 여부·리듬 안정도로 성취 확인 |
| 계획·기록 흩어짐 | 캘린더에서 통합 관리 |

## 5. 핵심 기능 (3개 고정)

### 기능1. 개인 맞춤 케이던스 가이드
- 러닝 전: 목표(시간/거리), 컨디션(가벼움/보통/피곤함), 경험·목표 난이도, 음성 on/off, 메트로놈 on/off
- 러닝 중: 시작 시 목표 범위 안내 → **범위 이탈이 일정 시간 지속될 때만** 음성/메트로놈 → 범위 안이면 무음
- 회복 어려우면 실측 케이던스 기준으로 목표 하향
- 상세 룰: `ENGINE.md`

### 기능2. 러닝 리포트 & AI 분석
- 기본 리포트: 목표/실제 시간·거리, 완주 여부, 범위 유지 시간, 평균 케이던스·페이스, 변화 그래프
- AI 리포트: 한 줄 판정 → 피로도(FI) → 인과 가설 → 다음 러닝 처방 → 다음 목표 추천
- `분석` 탭: 날짜별 리포트 목록, 상세, 추이, 완주 흐름, 추천 히스토리
- **의료 진단 아님.** 운동 습관 가설 + 다음 행동 제안

### 기능3. 러닝 루틴 캘린더
- 완료 체크 / 수기 기록 추가 / 미래 계획 / 수정·삭제·완료 / 날짜별 확인
- 기록 항목: 날짜, 시간 또는 거리, 방식(앱/직접), 컨디션 메모, 완료 여부
- **앱 안 켜고 뛴 날도 러닝 습관으로 인정**

## 6. 내비게이션
| 탭 | 내용 |
| --- | --- |
| 분석 | 리포트 목록·상세, 케이던스/페이스 그래프, 다음 목표 추천 |
| 홈 | 오늘 목표, 시간/거리 설정, 컨디션, 안내 방식, 시작 버튼, 최근 요약 |
| 기록 | 캘린더 80% + 프로필 20%, 우상단 설정(기본 정보/목표/음성·메트로놈/알림) |

## 7. 핵심 흐름
```
홈 → 목표 선택 → 컨디션 입력 → 케이던스 기준 확인·측정 → 러닝 시작
  → 필요한 순간에만 안내 → 종료 → 기본+AI 리포트 → 분석 탭 저장 → 캘린더 완료·다음 계획
```

## 8. 톤 규칙 (문구 작성 시 필독)
컨셉: **러닝메이트** — 과하게 격려하지 않고, 필요한 순간에만 정확하고 차분하게.

키워드: 친숙한 · 차분한 · 정확한 · 절제된 · 희망적인 · 실행을 돕는

| ✅ 쓸 것 | ❌ 안 쓸 것 |
| --- | --- |
| "오늘의 리듬을 시작해 볼까요?" | 말랑말랑·귀여운 분위기 |
| "지금은 조금 천천히 가도 괜찮아요." | 과도하게 친근한 말투 |
| "안정적인 리듬이에요. 그대로 이어가세요." | 불필요하게 긴 음성 안내 |
| "오늘도 한 번의 러닝을 기록했어요." | 기록 경쟁·압박 표현 |

러닝 중 음성: **1문장, 3초 이내.**

## 10. (미정) 게이미피케이션 — 누적 러닝 데이
`누적 러닝 데이` = 러닝한 날짜 총합. 매일 안 뛰어도 됨, 쉬어도 초기화 없음, 하루 여러 번 뛰어도 +1일.

| 행동 | 캘린더 | 누적 러닝 데이 |
| --- | --- | --- |
| 앱 러닝 완료 | 완료 표시 | +1 |
| 수기 기록 추가 | 수기 표시 | +1 |
| 계획 추가 | 예정 표시 | 변화 없음 |
| 계획일 미실행 / 휴식 | 미완료·빈 날짜 | 변화 없음 |

| 구분 | 수기 기록 | 앱 측정 |
| --- | --- | --- |
| 캘린더 표시 / 누적 활동일 | 반영 | 반영 |
| `달리 데이` 게임 수치 | 미반영 | 반영 |
| AI 케이던스 분석 / 목표 달성·보상 | 미반영 | 반영 |
